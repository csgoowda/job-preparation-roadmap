# 📚 SQL Learning Notes

A beginner-friendly collection of SQL notes covering the fundamentals of SQL, along with aggregate functions, grouping, and filtering grouped data. These notes are designed for students, interview preparation, and anyone learning relational databases.

---

## 📂 Repository Structure

```
.
├── SQL Basics.md
├── Aggregate Functions, GROUP BY, HAVING.md
└── README.md
```

## 📖 Contents

### 📘 SQL Basics.md
Covers the core concepts of SQL, including:

- Introduction to SQL
- Databases and Tables
- SQL Syntax
- Data Types
- Creating Databases
- Creating Tables
- Inserting Data
- Retrieving Data (`SELECT`)
- Filtering Data (`WHERE`)
- Sorting Results (`ORDER BY`)
- Updating Records (`UPDATE`)
- Deleting Records (`DELETE`)
- Table Constraints
- Primary Keys
- Foreign Keys

### 📊 Aggregate Functions, GROUP BY, HAVING.md

Explains how to summarize and analyze data using SQL.

Topics include:

- `COUNT()`
- `SUM()`
- `AVG()`
- `MIN()`
- `MAX()`
- `GROUP BY`
- `HAVING`
- Difference between `WHERE` and `HAVING`
- Practical Examples
- Interview Questions
