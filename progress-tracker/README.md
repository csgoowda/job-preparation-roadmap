# 📊 Progress Tracker

This directory contains your week-by-week progress tracking for the 8-week job preparation roadmap.

## 📋 How to Use These Templates

### Weekly Structure
Each week's file contains:
- **Weekly Overview** - Summary of targets vs. completed tasks
- **DSA Learning** - Topics and problems for the week
- **Development Learning** - Framework/tool topics
- **Projects** - Hands-on project work
- **Daily Breakdown** - Day-by-day progress
- **Achievements** - What you accomplished
- **Challenges** - Problems faced and solutions
- **Key Learnings** - Main takeaways
- **Next Week Goals** - Looking ahead

### Filling Out Your Progress

1. **Daily Updates** - Update your progress each day
   ```
   - [ ] Completed DSA problem X
   - [ ] Learned React concept Y
   - Time: 5 hours
   ```

2. **Problem Links** - Add LeetCode/CodeForces links
   ```
   | Problem # | Name | Link |
   |-----------|------|------|
   | 1 | Two Sum | https://leetcode.com/problems/two-sum |
   ```

3. **GitHub Commits** - Reference your commits
   ```
   - Commits: https://github.com/csgoowda/job-prep/.../commit/abc123
   ```

4. **Project Progress** - Update status regularly
   - [ ] Feature 1
   - [ ] Feature 2
   - [ ] Feature 3

### Status Indicators
- 🔄 In Progress
- ✅ Completed
- ❌ Not Started
- ⏸️ Paused
- 🆘 Stuck

### Difficulty Levels
- 🟢 **Easy** - Foundation level
- 🟡 **Medium** - Interview prep level
- 🔴 **Hard** - Advanced preparation

## 📊 Tips for Success

1. **Be Honest** - Record actual progress, not ideal progress
2. **Update Daily** - Small daily updates are better than weekly catch-ups
3. **Track Blockers** - Note what's slowing you down
4. **Celebrate Wins** - Document achievements to stay motivated
5. **Review Weekly** - Check previous weeks for patterns
6. **Adjust as Needed** - Don't be rigid; adapt the schedule if needed

## 📈 Metrics to Track

- **DSA:** Problems/week, Difficulty progression
- **Development:** Topics completed, Projects shipped
- **Consistency:** Commits/day, Study hours/day
- **Quality:** Code reviews, Bug fixes
