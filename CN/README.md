# Computer Networks Learning  Repository

This repository contains well-organized  notes and interview preparation materials for Computer Networks. It is designed for students, placement preparation, university exams, and technical interviews.

## Repository Structure

### 📘 Computer Networks Fundamentals 1

**File:** `Computer Networks Fundamentals 1.md`

Topics covered include:

* Introduction to Computer Networks
* Types of Networks (LAN, MAN, WAN)
* Network Topologies
* OSI Reference Model
* TCP/IP Model
* Network Devices
* Transmission Media
* Switching Techniques
* Error Detection and Correction
* Basic Networking Concepts

### 📗 Advanced Computer Networks 2

**File:** `Advanced Computer Networks 2.md`

Topics covered include:

* Routing Algorithms
* IPv4 and IPv6
* TCP and UDP
* Congestion Control
* Network Security
* Wireless Networks
* Software Defined Networking (SDN)
* Network Virtualization
* Cloud Networking
* Quality of Service (QoS)
* Computer Networks Interview Questions
* Placement Preparation Guide

1. Start with **Computer Networks Fundamentals 1.md**.
