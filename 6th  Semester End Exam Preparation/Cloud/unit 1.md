# 1. Introduction

Cloud Computing is one of the most important technologies in modern computing. It enables users to access computing resources such as **servers, storage, databases, networking, software, analytics, and applications** through the Internet without owning physical infrastructure.

According to the National Institute of Standards and Technology (NIST),

> **Cloud Computing is a model for enabling convenient, on-demand network access to a shared pool of configurable computing resources that can be rapidly provisioned and released with minimal management effort or service provider interaction.**

In simple terms, cloud computing allows users to use IT resources whenever needed and pay only for the resources they consume.

---

# 2. Definition

Cloud Computing is the **on-demand delivery of IT services over the Internet** using a **pay-as-you-go** pricing model. Instead of buying and maintaining hardware, organizations rent computing resources from cloud service providers like AWS, Microsoft Azure, and Google Cloud. 

---

# 3. Need for Cloud Computing

Traditional computing has several limitations:

* High infrastructure cost
* Expensive hardware maintenance
* Limited storage capacity
* Poor scalability
* High software licensing costs
* Time-consuming deployment

Cloud computing overcomes these limitations by providing resources on demand.

---

# 4. Cloud Computing Architecture

Cloud Computing architecture consists of two major parts:

## A. Front-End (Client Side)

The front-end is the user side where cloud services are accessed.

It includes:

* Desktop Computers
* Laptop
* Mobile Devices
* Thin Clients
* Web Browser
* Mobile Applications

The front-end sends requests to the cloud through the Internet.

---

## B. Back-End (Cloud Side)

The back-end is managed by the cloud service provider.

It includes:

* Servers
* Virtual Machines
* Databases
* Storage Systems
* Security Mechanisms
* Management Software
* Hypervisors
* Networking Components

The back-end processes user requests and allocates resources dynamically.

# 5. Working of Cloud Computing

The working process consists of the following steps:

### Step 1

The user opens a cloud application using a browser or mobile app.

### Step 2

The request is sent over the Internet.

### Step 3

The cloud management system authenticates the user.

### Step 4

Cloud servers allocate the required computing resources.

### Step 5

The application executes inside the cloud.

### Step 6

The requested data is returned to the user.

This entire process happens within a few seconds.

---

# 6. Characteristics of Cloud Computing

## 1. On-Demand Self-Service

Users can provision computing resources whenever required without human interaction.

---

## 2. Broad Network Access

Cloud services are accessible through laptops, smartphones, tablets, and desktops using the Internet.

---

## 3. Resource Pooling

Resources are shared among multiple users using a multi-tenant architecture.

---

## 4. Rapid Elasticity

Resources can be increased or decreased automatically based on demand.

---

## 5. Measured Service

Users are charged only for the resources they actually consume.

---

# 7. Advantages of Cloud Computing

According to your notes, the major advantages are: 

### Backup and Restore

Data stored in the cloud can be easily backed up and restored.

### Improved Collaboration

Multiple users can access and edit the same data simultaneously.

### Excellent Accessibility

Cloud services are available anywhere with an Internet connection.

### Low Maintenance Cost

The cloud provider maintains hardware and software.

### Mobility

Users can access resources while travelling using mobile devices.

### Unlimited Storage

Cloud providers offer scalable storage according to user requirements.

### Data Security

Cloud providers implement security mechanisms such as encryption, authentication, and backup.
