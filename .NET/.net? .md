## Part 1 — What is .NET?

Understand the platform before learning its code.

## Q1. What is .NET?

Answer: .NET is a free, open-source development platform created by Microsoft. Developers use it to build web applications, APIs, desktop software, cloud services and other applications.

Why do we need it?

Writing application code is only one part of software development. We also need tools to compile the code, execute it, manage memory and connect it to other systems. .NET provides many of these capabilities.

Example: You want to build a college management application. You can use .NET to build the backend that handles student registrations, attendance and marks.

## Q2. What is a platform?

Answer: A platform is a collection of tools, services and capabilities that helps developers build and run software.

Why do we need a platform?

Without a platform, developers would need to implement many common features themselves, such as memory management, networking and application execution.

Example: .NET provides a runtime, libraries and development tools so you can concentrate on your application's functionality.

## Q3. Is .NET a programming language?

Answer: No. .NET is a development platform, not a programming language.

- C# is a programming language.
- .NET is the platform that runs C# applications and provides libraries and tools.
- ASP.NET Core is a framework for building web applications and APIs on .NET.

Why does this distinction matter?

When you learn .NET backend development, you're generally learning C# as the language, .NET as the platform, and ASP.NET Core as the web framework.

## Q4. What can we build using .NET?

Answer: You can build several types of applications.

- Web APIs and backend services.
- Websites and web applications.
- Windows desktop applications.
- Cloud services and background workers.
- Mobile and cross-platform applications using suitable .NET frameworks.

Why is it useful?

You can learn one main programming language, C#, and apply it to different kinds of software.

## Q5. Is .NET free?

Answer: Yes. The .NET platform and SDK are free and open source. Visual Studio Code is also free.

Why does this matter?

You can learn .NET, practise coding, create projects and prepare for jobs without purchasing the development platform.

Some third-party tools, hosting services and enterprise products may have separate costs.

## Q6. What is C#?

Answer: C# (pronounced “C-sharp”) is a general-purpose programming language developed by Microsoft.

Why do we need it?

We use C# to write the instructions and business logic for an application.

Example: In a college application, C# code can check whether a student has passed a subject or calculate the total marks.

## Q7. What is the .NET SDK?

Answer: SDK stands for Software Development Kit. It contains the tools needed to create, build and run .NET applications, including the .NET CLI and compiler tooling.

Why do we need it?

Without the SDK, you generally cannot build a new .NET project using commands such as `dotnet new` and `dotnet build`.

Example:

```
dotnet --version
```

This checks which .NET SDK version is available through your terminal.

## Q8. What is the .NET Runtime?

Answer: The runtime provides the environment needed to execute a .NET application. It includes the Common Language Runtime (CLR) and supporting components.

Why do we need it?

Compiling a program and executing it are different tasks. The runtime provides services that help the compiled application execute.

Example: When you launch a compiled .NET application, the appropriate runtime runs it.

Remember: The SDK is for development; the runtime is for running applications. Installing the SDK normally also provides the relevant runtime components.

## Q9. What is CLR?

Answer: CLR stands for Common Language Runtime. It is the execution engine used by .NET.

Why do we need it?

It provides services such as garbage collection, exception handling and managed code execution.

Example: When your application creates objects in memory, the CLR's garbage collector can reclaim memory occupied by objects that are no longer being used.

You do not normally need to manage every memory allocation manually in C#.

## Q10. What are .NET libraries?

Answer: Libraries are reusable collections of code that provide ready-made functionality.

Why do we need them?

Developers shouldn't have to write everything from scratch.

Example: .NET libraries provide functionality for working with strings, dates, files, collections, networking and JSON.

Instead of writing your own code to format every date or parse every JSON document, you can use existing library functionality.

## Q11. What is a compiler?

Answer: A compiler translates source code into another form that can be executed or processed.

In a typical C# application, the C# compiler converts your code into Intermediate Language (IL), which is stored in the compiled assembly.

Why do we need it?

The runtime needs compiled instructions rather than simply treating your C# source file as the final executable program.

Example:

```
C# source code
      ↓
C# compiler
      ↓
IL in a compiled assembly
      ↓
.NET runtime
      ↓
Program executes
```

The runtime uses JIT compilation in common execution scenarios to translate IL into native machine code when needed.

## Part 3 — How does a .NET application work?

## Q12. What happens when we write a C# program?

Answer: In a typical compiled .NET application:

1. You write code in a `.cs` file.
2. The compiler checks and compiles the code.
3. The compiled assembly contains IL and metadata.
4. The .NET runtime loads and executes the application.
5. The application produces its result.

Why should you know this?

It helps you understand compilation errors, runtime errors and what the SDK and runtime actually do.

## Q13. What is managed code?

Answer: Managed code runs under the services of the .NET runtime.

Why is it useful?

The runtime provides services such as garbage collection and exception handling, making many common programming tasks easier and safer.

Example: Ordinary C# application code is typically managed code, although .NET applications can also interact with unmanaged code when required.

## Q14. What is garbage collection?

Answer: Garbage collection (GC) automatically reclaims memory used by managed objects that are no longer reachable.

Why do we need it?

It reduces the need for developers to manually allocate and free memory for ordinary managed objects.

Important: Garbage collection doesn't mean memory usage is unlimited. Applications still need good memory management and should release external resources, such as files and database connections, correctly.

## Q15. What is a .NET version?

Answer: A .NET version identifies a release of the platform, such as .NET 8 or .NET 10.

Why does it matter?

Different versions can have different features, support periods and compatibility requirements.

For new projects, prefer a supported release. LTS means Long-Term Support, which provides a longer support window than a standard-term release.

Example: Your project's `.csproj` file specifies its target framework, such as `net10.0`.

## Part 4 — What are ASP.NET Core and backend development?

## Q16. What is ASP.NET Core?

Answer: ASP.NET Core is a web framework built on .NET. It is used to develop websites, web applications and HTTP APIs.

Why do we need it?

C# by itself doesn't automatically provide a complete web server and web application framework. ASP.NET Core provides features such as routing, HTTP request handling, middleware, dependency injection and authentication integration.

## Q17. What is a backend?

Answer: The backend is the part of an application responsible for server-side processing and business rules.

Why do we need it?

Applications need a trusted place to validate requests, apply rules, manage access and work with stored data.

Example: When a student logs in, the backend validates their credentials and determines which information they can access.

## Q18. What is an API?

Answer: API stands for Application Programming Interface. It defines how one piece of software can interact with another.

In backend development, a Web API commonly exposes endpoints over HTTP.

Example: A frontend sends a request to `GET /students`, and the backend returns student data, often in JSON format.

Why do we need it?

It lets different applications communicate without needing to share their internal implementation.

## Q19. What is a database, and how does .NET connect to it?

Answer: A database stores and organises application data. .NET applications can communicate with databases such as PostgreSQL and SQL Server.

Why do we need it?

Most business applications must preserve information after a request finishes or an application restarts.

Example: A student API can save student details in PostgreSQL and retrieve them later. Entity Framework Core is one option for accessing the database from C#.

## Q20. What is the difference between .NET and Node.js?

Answer: Both can be used to build backend applications, but they use different runtimes and ecosystems.

| .NET ecosystem              | Node.js ecosystem                            |
| --------------------------- | -------------------------------------------- |
| Common language: C#         | Common language: JavaScript or TypeScript    |
| Web framework: ASP.NET Core | Frameworks: Express.js, NestJS               |
| Runtime: .NET CLR           | Runtime: JavaScript engine with Node.js APIs |

Why compare them?

Understanding the difference helps you see that .NET is an alternative backend technology, not an entirely different type of software development.
