# Time and Work - Top 5 Important Questions (Part 1)

These are the most frequently asked **Time and Work** questions in placement aptitude tests like **TCS, Infosys, Accenture, Capgemini, Cognizant, Wipro**, and other competitive exams.

# Question 1: A and B Working Together

## Question

A can complete a piece of work in **12 days** and B can complete the same work in **15 days**. If they work together, in how many days will they complete the work?

## What is the question asking?

We know **A's time** and **B's time**.

The question asks **how many days A and B will take together**.

Since **both are working together**, we **add** their one-day work.

## Solution

### Step 1: Find one-day work

A's one-day work = **1/12**

B's one-day work = **1/15**

### Step 2: Add both works

```
1/12 + 1/15
```

LCM of 12 and 15 = **60**

```
1/12 = 5/60

1/15 = 4/60
```

```
5/60 + 4/60 = 9/60
```

Simplify

```
9/60 = 3/20
```

This means **A and B complete 3/20 of the work in one day.**

### Step 3: Find total time

```
Time = 1 ÷ (3/20)

= 20/3

= 6⅔ days
```

## Answer

**6⅔ days (6 days 16 hours)**

### Shortcut

* Find one-day work.
* Add the one-day work.
* Take the reciprocal.

# Question 2: Find A's Time

## Question

A and B together can complete a work in **12 days**. B alone can complete the same work in **30 days**. In how many days can A alone complete the work?

## What is the question asking?

We know

* A + B
* B

We need to find **A**.

Since total work and B's work are known, we **subtract**.

## Solution

### Step 1: Find one-day work

A + B

```
1/12
```

B

```
1/30
```

### Step 2: Find A's one-day work

```
A = (A+B) - B

= 1/12 - 1/30
```

LCM = **60**

```
5/60 - 2/60

= 3/60

= 1/20
```

This means A completes **1/20** of the work in one day.

### Step 3: Find total time

```
Time = 20 days
```

## Answer

**20 days**

### Shortcut

**Together is given + Find one person = Subtract**

# Question 3: Men and Boys

## Question

If **4 men** or **6 boys** can complete a piece of work in **20 days**, then in how many days will **6 men and 11 boys** complete the same work?

## What is the question asking?

We need to find the time taken by **6 men and 11 boys working together**.

First find the work of **one man** and **one boy**.

## Solution

### Step 1: Find one-day work

4 men finish the work in 20 days.

```
4 men = 1/20

1 man = 1/80
```

6 boys finish the work in 20 days.

```
6 boys = 1/20

1 boy = 1/120
```

### Step 2: Find work of 6 men and 11 boys

```
6 × (1/80)

= 6/80
```

```
11 × (1/120)

= 11/120
```

LCM = **240**

```
18/240 + 22/240

= 40/240

= 1/6
```

They complete **1/6** of the work in one day.

### Step 3: Find total time

```
Time = 6 days
```

## Answer

**6 days**

### Shortcut

Find **one man's work** and **one boy's work**, then multiply by the required number.

# Question 4: Find C's Time

## Question

A can complete a work in **12 days**, B in **15 days**, and C in **20 days**. If all three work together, in how many days will they complete the work?

## What is the question asking?

We know the time taken by all three people individually.

We need to find the time taken **when all three work together**.

Since everyone is working together, we **add** their one-day work.

## Solution

### Step 1: Find one-day work

```
A = 1/12

B = 1/15

C = 1/20
```

### Step 2: Add

LCM = **60**

```
5/60 + 4/60 + 3/60

= 12/60

= 1/5
```

They complete **1/5** of the work in one day.

### Step 3: Find total time

```
Time = 5 days
```

## Answer

**5 days**

### Shortcut

If everyone is working together,

**Add everyone's one-day work.**

# Question 5: One Person Leaves

## Question

A can complete a work in **12 days** and B in **18 days**. They work together for **4 days**, after which B leaves. In how many more days will A finish the remaining work?

## What is the question asking?

The question asks:

* How much work is completed in the first 4 days?
* How much work is left?
* How long will A take to complete the remaining work alone?

## Solution

### Step 1: One-day work

```
A = 1/12

B = 1/18
```

Together

LCM = **36**

```
3/36 + 2/36

= 5/36
```

### Step 2: Work completed in 4 days

```
4 × 5/36

= 20/36

= 5/9
```

Completed work = **5/9**

Remaining work

```
1 - 5/9

= 4/9
```

### Step 3: A completes the remaining work

A's one-day work

```
1/12
```

Time

```
(4/9) ÷ (1/12)

= (4/9) × 12

= 16/3

= 5⅓ days
```

## Answer

**5⅓ days**

### Shortcut

* Find work completed together.
* Find remaining work.
* Divide remaining work by the one-day work of the person who continues.

# Question 6: Three People Working Together

## Question

A can complete a work in **20 days**, B in **30 days**, and C in **60 days**. In how many days will they complete the work together?

## What is the question asking?

We know the time taken by all three people individually.

The question asks **how many days they take together**.

Since everyone works together, **add** their one-day work.

## Solution

### Step 1: Find one-day work

A = **1/20**

B = **1/30**

C = **1/60**

### Step 2: Add all works

LCM = **60**

```text
1/20 = 3/60

1/30 = 2/60

1/60 = 1/60
```

```text
3/60 + 2/60 + 1/60

= 6/60

= 1/10
```

They complete **1/10** of the work in one day.

### Step 3: Find total time

```text
Time = 1 ÷ (1/10)

= 10 days
```

## Answer

**10 days**

### Shortcut

**If everyone works together → Add everyone's one-day work.**

# Question 7: Efficiency Based Question

## Question

A is **3 times as efficient as B**. B alone completes a work in **90 days**. In how many days can A complete the work?

## What is the question asking?

The question gives **efficiency**, not days.

Remember:

**Higher efficiency means less time.**

Efficiency and Time are **inversely proportional**.

## Solution

B takes **90 days**.

A is **3 times faster** than B.

So A needs only

```text
90 ÷ 3 = 30 days
```

## Answer

**30 days**

### Shortcut

**Time = Given Time ÷ Efficiency Ratio**

# Question 8: Wages Distribution

## Question

A completes a work in **6 days** and B in **8 days**. They work together and receive **₹2800**. How much money should A receive?

## What is the question asking?

Money is divided according to **work done**, not equally.

So first find their work ratio.

## Solution

A's work = **1/6**

B's work = **1/8**

Multiply both by LCM (24).

```text
1/6 = 4/24

1/8 = 3/24
```

Ratio

```text
A : B = 4 : 3
```

Total ratio

```text
4 + 3 = 7
```

A's share

```text
(4/7) × 2800

= ₹1600
```

## Answer

**₹1600**

### Shortcut

**Money is divided in the same ratio as work done.**

# Question 9: Alternate Day Working

## Question

A can complete a work in **10 days** and B in **15 days**. They work on alternate days, starting with A. In how many days will the work be completed?

## What is the question asking?

A works on Day 1.

B works on Day 2.

Again A on Day 3.

Again B on Day 4.

Continue until the work finishes.

## Solution

### Step 1: One-day work

A = **1/10**

B = **1/15**

### Step 2: Work done in two days

```text
1/10 + 1/15

= 3/30 + 2/30

= 5/30

= 1/6
```

Every **2 days**, they finish **1/6** of the work.

### Step 3: After 10 days

10 days = 5 cycles

```text
5 × 1/6

= 5/6 work
```

Remaining

```text
1 − 5/6

= 1/6
```

Now A starts the next day.

A's one-day work = **1/10**

Time needed

```text
(1/6) ÷ (1/10)

= 10/6

= 1⅔ days
```

Total time

```text
10 + 1⅔

= 11⅔ days
```

## Answer

**11⅔ days**

### Shortcut

Find **work done in one cycle**, then repeat the cycle until only a small part remains.

# Question 10: Pipes Filling a Tank

## Question

Pipe A fills a tank in **12 hours** and Pipe B fills it in **18 hours**. If both pipes are opened together, how long will it take to fill the tank?

## What is the question asking?

This question follows the **same concept as Time and Work**.

Instead of workers, we have **pipes**.

Since both fill the tank together, **add** their one-hour work.

## Solution

### Step 1: One-hour filling

A = **1/12**

B = **1/18**

### Step 2: Add

LCM = **36**

```text
1/12 = 3/36

1/18 = 2/36
```

```text
3/36 + 2/36

= 5/36
```

The pipes fill **5/36** of the tank every hour.

### Step 3: Find total time

```text
Time = 1 ÷ (5/36)

= 36/5

= 7.2 hours
```

```text
0.2 hour = 12 minutes
```

## Answer

**7 hours 12 minutes**

### Shortcut

**Pipes and Time & Work use the same formula.**

* Worker → Work
* Pipe → Tank Filling

Both use:

1. Find one-hour work.
2. Add or subtract.
3. Take the reciprocal to get the total time.

# Final Tips

## Remember These Rules

* **One-day work = 1 / Number of days**
* **Working together = Add**
* **Find one person's work = Subtract**
* **Time = Reciprocal of one-day work**
* **Higher efficiency = Less time**
* **Money is divided according to work done**
* **Pipes and Time & Work follow the same concept**
